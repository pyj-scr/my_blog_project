# 🌐 Context Native Translator (자연스러운 맥락 번역기)

> **어플 100엔 샾 (100-Yen App Shop)** 공식 등록 어플리케이션 v1.2.0

단순 직역 번역기를 넘어 비즈니스 메일, 일상 캐주얼, 학술 논문, 고객 응대 등 사용자가 원하는 뉘앙스(Tone)와 맥락에 맞추어 매끄러운 현지어 표현으로 변환해 주는 AI 맥락 번역 유틸리티 어플입니다.

---

## 🌟 주요 기능

1. **상황 및 어조(Tone) 선택 변환**:
   - 💼 비즈니스 메일 (정중하고 전문적인 격식체)
   - 💬 캐주얼 대화 (친근한 현지 대화체)
   - 🎓 학술 논문 (학술 서술체)
   - 🛍️ 커머스 / 고객 문의 (친절한 안내체)
2. **AI 맥락 인사이트 & 팁 제시**:
   - 원문의 어휘적 뉘앙스와 의역 포인트 안내
3. **원클릭 복사 & 음성 읽기(TTS)** 지원

---

## 🚀 사용 방법
- **웹/무설치 바로 실행**: `index.html` 파일 더블 클릭!
- **Python 프로그램 실행**: `run_app.bat` 또는 `python app.py` 실행
