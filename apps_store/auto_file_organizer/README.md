# 📁 Auto File Organizer Pro (스마트 폴더 정리)

> **어플 100엔 샾 (100-Yen App Shop)** 공식 등록 어플리케이션 v3.0.1

어지럽혀진 바탕화면과 다운로드 폴더 안의 무수한 파일들을 1초 만에 확장자별(이미지, 문서, 압축/설치, 미디어)로 깔끔하게 카테고리 폴더링해 주는 경량 자동화 유틸리티 어플입니다.

---

## 🌟 주요 기능

1. **원클릭 확장자 카테고리 자동 폴더링**:
   - 📷 **Images/**: png, jpg, jpeg, webp, gif, svg, ico
   - 📄 **Documents/**: pdf, doc, docx, txt, hwp, pptx, xlsx
   - 📦 **Archives/**: zip, rar, 7z, tar, exe, dmg
   - 🎬 **Media/**: mp4, avi, mkv, mp3, wav
2. **무설치 브라우저 시뮬레이터 & Python 데스크톱 앱 지원**

---

## 🚀 사용 방법
- **웹/무설치 바로 실행**: `index.html` 파일 더블 클릭!
- **Python 프로그램 실행**: `run_app.bat` 또는 `python app.py` 실행
