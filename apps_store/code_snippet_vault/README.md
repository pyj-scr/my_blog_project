# 🔐 Code Snippet Vault (개발자 코드 캡슐)

> **어플 100엔 샾 (100-Yen App Shop)** 공식 등록 어플리케이션 v1.1.0

자주 사용하는 코드 조각(Custom Hook, Python 래퍼, 정규식, SQL 쿼리, CSS 템플릿)과 비밀 설정값을 안전한 로컬 캡슐에 저장하고 키워드 초스피드 검색으로 꺼내 쓰는 개발자 유틸리티 툴입니다.

---

## 🌟 주요 기능

1. **초스피드 검색 & 언어 필터링**:
   - TypeScript, Python, CSS, SQL 언어별 분류 탭 및 검색 지원
2. **원클릭 클립보드 복사**:
   - 복사 버튼 하나로 IDE/에디터에 바로 붙여넣기
3. **로컬 스토리지 안전 보관**:
   - 외부 서버로 소스코드를 전송하지 않고 PC 로컬에만 안전하게 저장을 보장합니다.

---

## 🚀 사용 방법
- **웹/무설치 바로 실행**: `index.html` 파일 더블 클릭!
- **Python 프로그램 실행**: `run_app.bat` 또는 `python app.py` 실행
