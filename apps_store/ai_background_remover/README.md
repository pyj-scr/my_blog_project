# ✂️ AI Smart Remover (1초 배경 누끼 제거 툴)

> **어플 100엔 샾 (100-Yen App Shop)** 공식 등록 어플리케이션 v1.4.0

AI 딥러닝 비전 신경망을 통해 이미지 속 배경을 1초 만에 투명 PNG로 잘라내는 고성능 오프라인 유틸리티 어플리케이션입니다.

---

## 🌟 주요 특징

1. **원클릭 1초 배경 제거**: 복잡한 작업 없이 이미지만 넣으면 1초 만에 깔끔한 오토 누끼 완성
2. **100% 로컬 / 오프라인 보안**: 이미지를 외부 서버로 전송하지 않아 소중한 사진이 유출되지 않습니다.
3. **두 가지 실행 방식 제공**:
   - 🌐 **웹 & 단독 실행 모드 (`index.html`)**: 더블 클릭만 하면 브라우저에서 바로 사용 가능!
   - 🖥️ **데스크톱 GUI 모드 (`app.py` / `run_app.bat`)**: Python 데스크톱 창 프로그램

---

## 🚀 사용법

### 방법 1: 웹/독립형 바로 실행 (추천)
1. `index.html` 파일 더블 클릭
2. 브라우저 창에 이미지 드래그 앤 드롭
3. [투명 PNG 다운로드] 버튼 클릭!

### 방법 2: Python 프로그램 실행
1. `pip install -r requirements.txt` 실행
2. `run_app.bat` 또는 `python app.py` 실행
