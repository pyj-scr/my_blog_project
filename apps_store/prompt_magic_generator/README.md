# 🪄 Prompt Magic Generator (AI 프롬프트 생성기)

> **어플 100엔 샾 (100-Yen App Shop)** 공식 등록 어플리케이션 v1.0.5

원하는 주제 아이디어와 스타일 키워드 버튼을 누르기만 하면 최상의 Midjourney v6 및 ChatGPT 최적화 프롬프트를 1초 만에 생성해 주는 프롬프트 엔지니어링 툴입니다.

---

## 🌟 주요 기능

1. **Midjourney v6 고화질 파라미터 조합**:
   - 8k, photorealistic, cinematic lighting, 3D Octane render, Studio Ghibli 수채화 등 스타일 조합
   - `--ar 16:9`, `--v 6.0`, `--stylize 250` 자동 세팅
2. **ChatGPT 페르소나 (역할) 프롬프트 템플릿**:
   - 소프트웨어 개발자, 카피라이터, 비즈니스 컨설턴트, SEO 작성자 역할 자동 주입
3. **원클릭 클립보드 복사**: 복사 버튼 하나로 AI 툴로 바로 붙여넣기 가능

---

## 🚀 사용 방법
- **웹/무설치 바로 실행**: `index.html` 파일 더블 클릭!
- **Python 프로그램 실행**: `run_app.bat` 또는 `python app.py` 실행
