# 📄 PDF AI Summarizer (원클릭 요약기)

> **어플 100엔 샾 (100-Yen App Shop)** 공식 등록 어플리케이션 v2.1.2

논문, 보고서, 계약서 등 50페이지 분량의 길고 복잡한 PDF 문서를 10초 만에 핵심 요약 노트, 주요 키워드 Top 5, 실행 가능한 액션 아이템으로 깔끔하게 정리해 주는 오피스 생산성 툴입니다.

---

## 🌟 주요 기능

1. **인브라우저 PDF.js 파싱**:
   - 외부 서버에 업로드하지 않고 브라우저에서 텍스트를 바로 파싱하여 보안에 안전합니다.
2. **3가지 구조화된 요약 노트**:
   - 핵심 3줄 요약
   - 주요 키워드 Top 5
   - 권장 실행 과제 (Action Items)
3. **원클릭 복사 & TXT 저장 지원**:
   - 요약 결과를 클립보드에 복사하거나 텍스트 파일로 저장

---

## 🚀 사용 방법
- **웹/무설치 바로 실행**: `index.html` 파일 더블 클릭!
- **Python 프로그램 실행**: `run_app.bat` 또는 `python app.py` 실행
